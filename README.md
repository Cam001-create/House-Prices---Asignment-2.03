# House Prices: Exploratory Data Analysis

**Camila Lopez**

Exploratory analysis of the Kaggle House Prices dataset
to answer one question: **what makes a house more expensive?**

## Main findings

A house's price depends mostly on **how well it is built** and **how big it is**; **where** and **when** it was built come next.

1. **Quality**: an excellent house sells for 3.3× an average one (correlation 0.79).
2. **Size**: more living space, higher price (correlation 0.71).
3. **Location**: the best neighborhood costs 3.6× the cheapest.
4. **Age**: newer houses sell for about 1.8× older ones.

A typical house sold for about **$163,000**. Most missing values simply mean the house doesn't have that feature (for example, 99.5% have no pool).
